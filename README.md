Module Odoo de Gestion des Absences et Justifications
Description
Ce dépôt contient le code source et la documentation d’un module Odoo nommé DBSence, dédié à la gestion des absences et des justifications dans un contexte éducatif ou professionnel.
Ce projet a été réalisé dans le cadre d’un projet de fin d’année par Bouakhsas Anas, encadré par Pr. Ait Daoud, durant l’année académique 2025-2026.
Le module permet d’enregistrer, suivre et gérer efficacement les absences tout en offrant la possibilité d’ajouter des justifications associées, de gérer des pièces jointes et de suivre un workflow de validation.
Principaux avantages :

Centralisation des données pour remplacer les méthodes manuelles (tableurs, papier).
Intégration d’un workflow de justification, de boutons d’actions métiers et d’une interface optimisée.
Respect des bonnes pratiques de développement Odoo (Python et XML).

Pour plus de détails, consultez le rapport complet du projet : odoo.pdf.
Fonctionnalités

Enregistrement des absences : Création et modification avec date, motif, étudiant/employé.
Gestion des justifications : Ajout de justifications liées à une absence, changement d’état (en attente, approuvée, refusée).
Workflow intégré : Automatisation des changements d’état et validation.
Gestion des pièces jointes : Téléversement de documents justificatifs (ex. : certificats médicaux).
Interfaces utilisateur : Vues personnalisées (liste, formulaire, kanban), menus et recherches avancées.
Sécurité des données : Accès basés sur les rôles (administrateur, responsable pédagogique, étudiant).
Traçabilité : Historique et logs des actions.
